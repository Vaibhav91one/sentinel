Sentinel · Architecture

Scope-enforced security recon agent on the TrueForge harness · Agent Harness Hackathon submission · repo: github.com/Vaibhav91one/sentinel

01 · High-level architecture

Four cooperating planes. The harness owns orchestration and human checkpoints. The policy plane (our TypeScript MCP server) owns authorization decisions and consent bookkeeping. The execution plane is a disposable cloud sandbox where both the scanner and the target live. The enrichment plane reaches CVE data that the sandbox's restricted egress cannot.

02 · Assessment lifecycle (one full run)

Lab buildSandbox provisions on first exec need. Agent clones repo from GitHub (allowlisted egress), installs Node, starts vuln-app on sandbox-localhost:3000.
Scope gateEvery contact preceded by scope_check. localhost matches default entry. Deny ⇒ no contact at all.
Passive reconcurl fingerprinting inside sandbox: banners, headers, link graph. No approval needed. Findings → artifacts/*.recon.jsonl.
Consent checkpointrequest_intrusive_approval is annotated destructive ⇒ harness pauses turn, renders Allow/Deny card. Human decides.
Grant mintedOn Allow: guard verifies scope again, mints single-use token (10-min TTL). Agent embeds SENTINEL_GRANT=… in active commands; confirms via verify_grant.
Active scannmap top-ports sweep + curated web probes (rate-limited). Evidence captured to artifacts, not pasted into chat.
CVE correlationHost-side osv_query per versioned package; osv_get for detail. Reachability reasoning downgrades unverifiable advisories.
ReportSeverity-ranked markdown + machine-readable JSON in artifacts. Audit log holds every decision end-to-end.

Transport & process model

Stateless Streamable-HTTP MCP: one McpServer + one StreamableHTTPServerTransport (sessionIdGenerator: undefined) per POST — no sessions to leak, horizontal scaling trivial. Node http.createServer, no framework. Binds 127.0.0.1 only.

Bearer gate: when GUARD_TOKEN env is set, every POST must carry Authorization: Bearer …; mismatches get 401 and an audit entry. The same value lives in the TrueForge connector's header-auth config — that shared secret IS the trust boundary.

Fail-closed posture: REQUIRE_GUARD_TOKEN=1 without a configured token blocks all mutations (add/remove/grants), not just grants.

scope_check decision pipeline

target string
   │
   ▼
normalizeTarget()          URL-parse (scheme optional) → hostname + port [+ path for display]
   │ null ⇒ DENY unparseable
   ▼
classify(host[:port])
   ├─ cloud_metadata  ⇒ DENY (hard, never overridable)
   ├─ link_local      ⇒ DENY (hard)
   ├─ reserved        ⇒ DENY (hard)          ← 0/8 · 100.64/10 · 198.18/15 · TEST-NETs
   │                                          ← 192.0.0/24 · 224/4 · 240/4 · ::/128
   │                                          ← multicast ff00::/8 · doc 2001:db8::/32
   ▼
matches(allow[])?          exact host[:port] · IPv4 CIDR overlap · *.wildcard suffix
   │ no match ⇒ DENY "no scope entry"
   ▼
needsResolution?           skip for IP literals and CIDR entries
   │ yes ⇒ dns.lookup(all)
   │   throw            ⇒ DENY fail-closed (NXDOMAIN etc.)
   │   []               ⇒ DENY fail-closed (zero usable addresses)
   ▼
resolvedClasses = classify(each answer)
   ├─ metadata ∨ link_local ∨ reserved  ⇒ DENY rebinding/tripwire
   ├─ cls==public  ∧ (private|loopback) ⇒ DENY rebinding
   ├─ cls!=public  ∧  public answer     ⇒ DENY class mismatch
   ▼
ALLOW · matched entry recorded · audit.append()

Grant state machine

                    request_intrusive_approval(target, action)
                              │ scope.check fails? ──▶ DENIED (audited, no token exists)
                              ▼
                     [harness pause: Allow / Deny card]
                              │ Deny ──▶ tool never executes
                              ▼ Allow
                     mintGrant(canonical_target, action)
                     grants[token] = { target, action, expires_at: now+10min }
                              │
                              ▼
             agent embeds SENTINEL_GRANT= in commands
                              │
                              ▼
                  verify_grant(token, target)          ← also callable ad hoc
   unknown?            → invalid (no state change)
   expired?            → delete + invalid
   wrong target?       → invalid, GRANT KEPT (typo must not burn approval)
   match               → DELETE + valid            ◀── single use consumed here

Honest boundary: consumption is bookkeeping. Nothing yet blocks a command that omits the variable — enforcement arrives with the planned sandbox-side egress proxy. Documented in README §known-limits and policy_get.

04 · Data schemas

data/scope.json

{
  "allow": [
    "localhost",
    "127.0.0.1",
    "::1",
    "10.50.77.0/24",        // CIDR
    "*.trycloudflare.com",  // wildcard domain
    "[2606:4700::1111]:443" // bracketed v6 + port
  ],
  "updated_at": "2026-08-25T…"
}
  • Loaded through the sanitizer: every entry re-passes add()-time validation; violating entries quarantined with a warning, sanitized policy written back.
  • v6 stored canonically (RFC 5952 compression).

data/audit.jsonl

{"ts":"2026-08-25T…","actor":"agent",
 "action":"scope_check",
 "args":{"target":"http://localhost:3000"},
 "verdict":"allowed",
 "reason":"matches scoped entry \"localhost\"" }

{"ts":"…","actor":"human-via-agent",
 "action":"intrusive_request",
 "args":{"target":"…","action":"port sweep",
         "grant":"b7d911f6…"},   // 8-char fingerprint only
 "verdict":"allowed",
 "reason":"human Allow/Deny enforced upstream …"}

Append-only. Actors: agent (autonomous), human-via-agent (post-checkpoint). Verdicts: allowed / denied / mutated.

09 · Runbook

# one-time
pnpm install && pnpm build
cp .env.example .env            # add DEEPSEEK_API_KEY (+ optional GUARD_TOKEN)

# every session
pnpm scope-guard &              # policy plane   → http://127.0.0.1:9930/mcp
pnpm harness                    # TrueForge      → http://localhost:8790

# assess (scripted driver, auto-handles approval pauses)
node --env-file=.env scripts/full-assess.mjs http://localhost:3000

# watch money + decisions
node --env-file=.env scripts/usage.mjs status
tail -f data/audit.jsonl
